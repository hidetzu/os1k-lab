# 03 OSの全体像

教材：[OSの全体像 | OS in 1,000 Lines](https://operating-system-in-1000-lines.vercel.app/ja/03-overview)

## この章の位置づけ

OS が持ちうる機能のうち、「1000行で OS を理解するのに必要」と考えて選んだ範囲を示す章。何を作るかと同時に、何を作らないかの選択の話として読む。

## 実装する機能

「動くモード」は教材の説明からの推論で、コードではまだ確かめていない。

| 機能                 | 中身                                                                 | 動くモード |
| -------------------- | -------------------------------------------------------------------- | ---------- |
| マルチタスク         | プロセスを切り替えて、複数のプログラムが同時に動いているように見せる | S          |
| 例外ハンドラ         | 実行時エラーなど、CPU が OS の対応を必要とするイベントを処理する     | S          |
| ページング           | プロセスごとに独立したメモリ空間を作る                               | S          |
| システムコール       | アプリが OS の機能を呼び出す入口                                     | U → S      |
| デバイスドライバ     | ディスクの読み書きなどのハードウェア操作                             | S          |
| ファイルシステム     | ディスク上のファイルを管理する                                       | S          |
| コマンドラインシェル | 利用者がコマンドで OS の機能を使う                                   | U          |

## 実装しない機能

| 省かれる機能         | 代わりにどうしているか                                                      |
| -------------------- | --------------------------------------------------------------------------- |
| 割り込み処理         | デバイスを定期的に確認するポーリングで代用                                  |
| タイマー処理         | プリエンプティブではなく、各プロセスが自分から CPU を譲る協調的マルチタスク |
| プロセス間通信       | なし                                                                        |
| マルチプロセッサ対応 | シングルプロセッサのみ                                                      |

教材によれば、これらは後から追加できる。筆者の別の OS である HinaOS が参考になるとのこと。

## ファイル構成

最終的な構成（教材より）。「動くモード」は推論で、未確認。

| ファイル                | 役割                                                                                         | 動くモード     |
| ----------------------- | -------------------------------------------------------------------------------------------- | -------------- |
| `kernel.c` / `kernel.h` | カーネル本体（プロセス管理、システムコール、デバイスドライバ、ファイルシステム）と、その定義 | S              |
| `kernel.ld`             | カーネルのリンカスクリプト（メモリ上の配置を決める）                                         | ―              |
| `user.c` / `user.h`     | アプリ用ライブラリ（システムコールを呼ぶ関数など）と、その定義                               | U              |
| `user.ld`               | アプリのリンカスクリプト                                                                     | ―              |
| `shell.c`               | コマンドラインシェル                                                                         | U              |
| `common.c` / `common.h` | カーネルとアプリで共通に使うライブラリ（`printf`、`memset` など）と、共通の定義              | S と U の両方  |
| `run.sh`                | ビルドと起動のスクリプト                                                                     | ホスト（Arch） |
| `disk/`                 | ファイルシステムに入れる中身                                                                 | ―              |

`kernel.ld` は、最初の問い「カーネルを誰がどの番地に置くのか」に直接関係するファイル。`riscv-intro.md` に書いた `0x8020_0000` の出どころもここのはず。
