# 学習ノート目次

『1000行でOSを作ってみよう』（[OS in 1,000 Lines](https://operating-system-in-1000-lines.vercel.app/ja/)）を主教材に、32ビット RISC-V の小さな OS を作りながら、コンピュータが起動してアプリを動かすまでを理解する。

最初の問い：カーネルを誰がメモリに配置し、CPU はどうやって自分が書いた最初の命令に到達するのか。
